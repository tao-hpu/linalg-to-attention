# 线性代数 → 注意力

> 可视化地，从一个向量一路搭到 Transformer 的注意力机制。
> 说人话：**手搓大模型之前的那门预科课** 😎

**🔗 在线访问 → [l2a.fim.ai](https://l2a.fim.ai)** ·  动手拖一拖，比看十遍公式管用。

这不是又一份"看动画"的演示，也不是一摞"给你代码"的清单。每一页只回答**一个「为什么」**——你拖动滑块、亲手改参数，看几何当场变化，然后页底一句话把它焊到 LLM 上：*这就是注意力里的那一步*。风格对标"从零实现 GPT"，只不过我们从更底层的数学搭起。

**学完你能**：看懂注意力的每一步，并在之后碰 LLM 的**训练 / 微调 / 推理**时，知道每个环节背后的数学在做什么——而不是只会调包。

## 两根支柱

- **几何（线性代数）**：向量、矩阵、SVD、特征值——每个概念都还原成一个能拖动的几何动作。
- **概率（经典统计）**：softmax、交叉熵、极大似然、正则化——把"猜下一个词"讲成一个概率模型。

两者在「注意力」里合流，在「训练 / 微调 / 推理」里落地。

## 大纲（共 39 节 · 10 部分） — ✅ 全部上线

1. **向量：意义的载体** — 向量与坐标系 · 从词袋到词向量 · 加减与缩放 · **内积** · 投影 · 范数
2. **矩阵：一个动作** — 矩阵是变换 · **矩阵乘法的几何** · 四种视角 · 转置与形状 · 批量与张量
3. **方阵的秘密** — 行列式 · **矩阵的秩** · 逆矩阵 · 特征值 · 谱分解
4. **正交、回归与投影** — 正交矩阵与旋转 · 正交投影 · 格拉姆-施密特与 QR · 回归=投影
5. **降维** — SVD · 低秩近似（LoRA）· PCA
6. **学习** — 梯度 · 链式法则与 Jacobian · 梯度下降 · 正则化（Ridge/Lasso）· 归一化
7. **概率视角** — Softmax · 交叉熵与极大似然
8. **合成：拼出注意力** — 自注意力 · 因果掩码 · 多头注意力 · 位置编码与 RoPE · Transformer Block
9. **尾声：接到 LLM 工程** — LoRA 微调 · 采样与解码 · 量化
10. **终点：完整的前向传播** — 跑通一次前向传播

> 章节清单的唯一事实来源是 `src/chapters.ts`，首页大纲、侧栏、翻页、sitemap 都从它生成。

> ★ 标记的是"通往注意力的最短主线"。每节一个交互可视化 + 一段「这就是 LLM 里的什么」。

## 技术栈

Vite + React 18 + TypeScript，可视化全部用 SVG 手绘（轻量、无重型依赖），代码高亮用 prism-react-renderer，瑞士蓝（IKB）简约风。

## 本地运行

```bash
pnpm install
pnpm dev      # http://localhost:5191
pnpm build    # 产物在 dist/
```

## 部署（aws-hk · Docker + nginx）

服务器端 pull 式部署，和本机其他项目一致：

```bash
ssh aws-hk
git clone git@github.com:tao-hpu/linalg-to-attention.git ~/linalg-to-attention
cd ~/linalg-to-attention
docker compose up -d --build    # build 镜像 + 起容器，监听 127.0.0.1:5191
```

容器只监听本地端口，公网流量由服务器上的 nginx 反代到对应域名。
更新时在服务器上 `git pull && docker compose up -d --build` 即可。
